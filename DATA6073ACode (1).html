Approach

What are the top three movies we would recommend to each user who hasn’t rated everything?

Introduction

In this assignment, we will build a “movie recommender” using the Global Baseline Estimate algorithm. The data comes from a survey where several people rated a set of movies, and most of them did not rate every movie.

Planned Approach

First we will read the movie ratings spreadsheet into R. The data has one row per user and one column per movie, with missing values where someone did not rate a film. We will reshape it into long format so that each row is one user–movie pair, which makes the calculations easier.

The idea behind the Global Baseline Estimate is simple. To recommend a movie to someone, we need to guess how much they would like the films they haven’t seen yet, so that we can rank those films and pick the best ones. The algorithm makes that guess by starting from the average rating across the whole survey and then adjusting it twice: once for how generous or harsh that particular user tends to be, and once for how well-liked that particular movie is overall. A user who rates everything highly gets an upward adjustment, and a movie that everyone enjoyed gets an upward adjustment too.

Anticipated Challenges

Some movies were rated by only a few people, so the numbers for those films may not be reliable.

We also need to be careful with the missing values. If we treat unrated movies as zeros instead of missing, the averages will come out wrong.

Finally, this method is not personalized, since it never looks at what kind of movies a person enjoys. We expect the users’ top three lists to look similar, and we want to discuss that in our conclusion.

overall_mean <- mean(ratings_matrix, na.rm = TRUE)

user_avg   <- rowMeans(ratings_matrix, na.rm = TRUE)
user_bias  <- user_avg - overall_mean

movie_avg  <- colMeans(ratings_matrix, na.rm = TRUE)
movie_bias <- movie_avg - overall_mean

# Baseline for every user/movie pair: mu + user_bias + movie_bias
baseline <- outer(user_bias, movie_bias, FUN = "+") + overall_mean
dimnames(baseline) <- dimnames(ratings_matrix)

# Ratings are on a 1-5 scale, so clip estimates to that range
baseline_clipped <- baseline
baseline_clipped[baseline_clipped > 5] <- 5
baseline_clipped[baseline_clipped < 1] <- 1

top_n_recommendations <- function(user, mat, baseline_matrix, n = 3) {
  unrated <- names(which(is.na(mat[user, ])))
  if (length(unrated) == 0) return(NULL)
  preds <- sort(baseline_matrix[user, unrated], decreasing = TRUE)
  head(preds, n)
}

incomplete_users <- responders[apply(is.na(ratings_matrix), 1, any)]

for (u in incomplete_users) {
  recs <- top_n_recommendations(u, ratings_matrix, baseline_clipped, n = 3)

      recommendation_table,
      data.frame(User = u, Rank = k, Movie = names(recs)[k],
                 Predicted = round(unname(recs[k]), 3),
                 stringsAsFactors = FALSE)
    )
  }
}
